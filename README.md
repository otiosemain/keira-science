# Keira 的五年级科学 / Standard 5 Science

Bilingual (Chinese + English) study notes for Yuk Chai Standard 5 Science.

**Site:** https://otiosemain.github.io/keira-science/

Open the site in any browser. Each unit has notes, flashcards and a self-marking quiz. Printable PDF notes and glossaries are linked from the home page.

`*.pdf.b64` files, if present, are encoded copies of the printable notes. GitHub Actions decodes them when publishing the site.
